# 📱 termux-mcp-bridge

🌐 [English](README.md) · [Русский](README.ru.md) · [Čeština](README.cs.md)

**Дай своему ИИ-ассистенту руки на твоём Android-телефоне.**
Маленький [MCP](https://modelcontextprotocol.io)-сервер без зависимостей. Он работает в [Termux](https://termux.dev) и позволяет ИИ-клиентам вроде Claude, ChatGPT или Notion AI выполнять команды, открывать приложения, присылать уведомления, узнавать заряд батареи и геолокацию и многое другое. Без root, без ADB и без компьютера.

```
ИИ-клиент ──HTTPS──▶ Cloudflare quick tunnel ──▶ 127.0.0.1:8765 (Termux) ──▶ твой телефон
                        (секретный путь в ссылке)
```

## ✨ Возможности

- **Установка одной командой.** Ничего не надо настраивать и не надо создавать аккаунты.
- **Без проброса портов.** Работает через бесплатный Cloudflare quick tunnel, поэтому подходит и мобильный интернет, и любой Wi-Fi.
- **Самовосстановление.** Сторож сам перезапускает сервер и туннель, если связь пропала.
- **Постоянная ссылка** через бесплатный Cloudflare Worker (по желанию).
- **Больше не надо копировать ссылки.** Каждая новая ссылка туннеля публикуется в твой приватный канал [ntfy](https://ntfy.sh), и ИИ всегда находит актуальную.
- **Автозапуск после перезагрузки** через Termux:Boot.
- **Ноль npm-зависимостей.** Около 120 строк чистого Node.js.

## 🛠 Инструменты

| Инструмент | Что делает |
|---|---|
| `shell` | Выполнить любую команду в Termux |
| `list_apps` | Список установленных приложений (с фильтром) |
| `open_app` | Открыть приложение по имени пакета |
| `open_url` | Открыть ссылку в браузере или подходящем приложении |
| `notify` | Показать уведомление |
| `phone_status` | Батарея, зарядка, температура, Wi-Fi, громкость |
| `location` | Геолокация (GPS / сеть) |
| `clipboard` | Прочитать или записать буфер обмена |
| `speak` | Сказать текст вслух (TTS) |

**Что ИИ не сможет:** видеть экран и нажимать кнопки в других приложениях, читать переписки в чужих приложениях, менять системные настройки (нужен root), работать без интернета или при выключенном телефоне.

## 🚀 Установка

1. Установи из **F-Droid** (не из Google Play):
   - [Termux](https://f-droid.org/packages/com.termux/)
   - [Termux:API](https://f-droid.org/packages/com.termux.api/): нужен для уведомлений, батареи, геолокации, буфера обмена и озвучки
   - [Termux:Boot](https://f-droid.org/packages/com.termux.boot/) *(по желанию)*: автозапуск. После установки открой его один раз.
2. В Termux выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/belacorc/termux-mcp-bridge/main/install.sh | bash
```

Установщик покажет твою **MCP-ссылку** и **приватный канал ntfy**.

3. Добавь ссылку в ИИ-клиент как удалённый MCP-сервер (Streamable HTTP), например:

```json
{ "mcpServers": { "phone": { "url": "https://xxxx.trycloudflare.com/mcp/<token>" } } }
```

### Локальный режим stdio

Чтобы запускать мост из локального MCP-клиента внутри Termux, без туннеля:

```json
{ "mcpServers": { "phone": { "command": "node", "args": ["/data/data/com.termux/files/home/termux-mcp-bridge/bridge.mjs", "--stdio"] } } }
```

## 🔁 Каждый день

```bash
~/termux-mcp-bridge/start.sh   # запустить (после перезагрузки запускается сам)
~/termux-mcp-bridge/stop.sh    # остановить
```

Ссылка quick tunnel меняется при каждом перезапуске. Актуальную всегда можно получить так:

```bash
curl -s "https://ntfy.sh/<твой-канал>/json?poll=1&since=24h" | tail -n 1
```

Или через помощник [`client/phone.sh`](client/phone.sh):

```bash
export BRIDGE_TOPIC=pb-xxxxxxxx
./client/phone.sh phone_status
./client/phone.sh shell '{"command":"uname -a"}'
```

## 🔗 Постоянная ссылка (по желанию, бесплатно)

Ссылка туннеля меняется при каждом перезапуске, и чат-ИИ (Claude, ChatGPT) пришлось бы каждый раз давать новую. Это решает маленький Cloudflare Worker из [`relay/worker.js`](relay/worker.js): он берёт актуальную ссылку из твоего канала ntfy и пересылает запросы туда. Твоя ссылка **больше никогда не меняется**:

```
https://phone.<твой-поддомен>.workers.dev/mcp/<token>
```

1. Создай бесплатный аккаунт Cloudflare и открой **Workers & Pages → Create → Start with Hello World**. Назови его `phone` и нажми Deploy.
2. Нажми **Edit code**, вставь `relay/worker.js`, потом **Deploy**.
3. В **Settings → Variables and Secrets** добавь секрет `TOPIC` с названием своего канала ntfy.
4. Добавь в ИИ-клиент ссылку `https://phone.<твой-поддомен>.workers.dev/mcp/<token>`. Токен лежит в `~/.bridge_token`.

Worker пересылает только пути `/mcp/*`, а телефон всё равно проверяет токен, поэтому на неправильный токен придёт 404.

## 🔒 Безопасность

> ⚠️ **MCP-ссылка = полный доступ к командной строке твоего Termux.** Береги её как пароль.

- Сервер слушает только `127.0.0.1`. Снаружи до него можно достучаться только через туннель и только по секретному пути `/mcp/<случайный 144-битный токен>`. На любой другой путь он отвечает 404.
- Токен хранится в `~/.bridge_token`. Чтобы сменить его, удали файл и перезапусти мост.
- Название канала ntfy тоже случайное и тоже является секретом: кто его знает, тот может прочитать твою текущую ссылку. Никому его не давай.
- Если мост не нужен, выключи его через `stop.sh`.
